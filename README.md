First assessment task for Y9 100 Computing 2026

# Instructions

Upon entering the interface, you will be greeted with a numbered list of choices for what you can do with the interface. The choices are:

    1. View a dataset
    2. Exit the interface
    3. Edit a data value

The interface will ask you what choice you want to input. You MUST input the number placed next to the choice (e.g. if you want to view a dataset you must type in only the number 1).

If you choose 1, another numbered list of choices will appear, asking if you would like to see just a raw, written dataset or the visualisation of a dataset. You will go through the same process as with when entering the interface, where you will be greeted with (surprise) ANOTHER NUMBERED LIST of choices, specifically which dataset you would like displayed. You do the same process again, upon which you will either see a table of values (if you chose the raw dataset option) or a graph (if you chose the visualisation option). After you have gazed upon whatever you have chosen, you will be requested to return back to the main menu.

If you chose 3, you will be brought to another numbered list of choices, specifically which dataset you would like to edit. Upon choosing your dataset, the table of values of the dataset will be printed and, through typing in which column and row respectively (or just row, depending on the dataset) you would like to edit, can edit a value in the table through a text prompt. Upon this, the table will be reprinted with the edited value, and you will be requested on whether you would like to save your changes or not. If you type yes, then the changes will be saved back into the existing dataset, and if not, then you simply return back to the main menu. 

NOTE THAT IF ANY IMPROPER VALUES ARE TYPED, THE INTERFACE WILL STOP FUNCTIONING AND YOU WILL HAVE TO RETURN BACK TO THE START

If you choose 2, then you will simply exit the interface. Note that you may have to enter 2 multiple times before you finally exit.

Note that this only represents a small demographic of the GHS population and therefore shouldn't be relied on as a representation of the entire GHS population as a whole.
