### HYPOTHESIS

Year 9 students spend more time on their screens daily then reading a book weekly.

### Functional Requirements

* The data would be visualised as either a Pandas dataframe or a Matplotlib bar chart (with the x-axis being the amount of time spent on their screens daily, y-axis being how long they spend reading a book weekly) depending on the user's choice.

* 

### Non-Functional Requirements

* The user interface should be easy to navigate and it should be designed in a way so that a user can naviagate it without confusion from the start.

* The README file should explain clearly how the module works in case the user doesn't understand.
